To delete the instance 

 Invoke-RestMethod `
>>   -Method DELETE `
>>   -Uri "http://127.0.0.1:8081/instance/delete/codex-temp-test" `
>>   -Headers @{ apikey = "my_super_secret_key_123" }
>>


to test the instance is deleted or not 

Invoke-RestMethod `
  -Method GET `
  -Uri "http://127.0.0.1:8081/instance/fetchInstances?instanceName=codex-temp-test" `
  -Headers @{ apikey = "my_super_secret_key_123" }
