Create backup folder:

mkdir -p /backup/mysql


Create backup script:


nano /root/mysql_backup.sh


file content

#!/bin/bash

DATE=$(date +%F_%H-%M-%S)
BACKUP_DIR="/backup/mysql"
DB_NAME="YOUR_DB_NAME"
EMAIL="YOUR_GMAIL@gmail.com"
FILE="$BACKUP_DIR/${DB_NAME}_$DATE.sql"
ARCHIVE="$FILE.gz"

mysqldump --defaults-extra-file=/root/.my.cnf "$DB_NAME" > "$FILE"

if [ $? -eq 0 ] && [ -s "$FILE" ]; then
    gzip "$FILE"

    if [ -s "$ARCHIVE" ]; then
        rclone copy "$ARCHIVE" gdrive:mysql-backups/

        if [ $? -eq 0 ]; then
            MESSAGE="SUCCESS: MySQL backup created and uploaded: $ARCHIVE"
        else
            MESSAGE="WARNING: Backup created locally but Google Drive upload failed: $ARCHIVE"
        fi
    else
        MESSAGE="FAILED: Backup file compression failed"
    fi
else
    MESSAGE="FAILED: mysqldump backup failed"
fi

echo "$MESSAGE" | mail -s "MySQL Backup Status" "$EMAIL"

find /backup/mysql -type f -mtime +14 -delete

Correct command

docker-compose rm -sf app
docker-compose up -d --no-deps app

Explanation 

docker-compose rm -sf app → removes the old container (avoids the buggy "recreate" path that reads ContainerConfig).
docker-compose up -d --no-deps app → creates a fresh container from the image you already built → no crash.
