Install Netdata :

bash <(curl -L https://my-netdata.io/kickstart.sh)

Enable Email Alerts (Netdata)

sudo nano /etc/netdata/health_alarm_notify.conf

chnages to make 

SEND_EMAIL="YES"
DEFAULT_RECIPIENT_EMAIL="your-email@gmail.com"

Restart Netdata

sudo systemctl restart netdata


check the status

sudo systemctl status netdata

Open dashboard

http://YOUR_SERVER_IP:19999

Install Uptime Kuma only (Docker)

This runs Uptime Kuma as a separate standalone container.
Do not add this to docker-compose.yml.

docker run -d \
  --name uptime-kuma \
  --restart=always \
  -p 3001:3001 \
  -v uptime-kuma:/app/data \
  louislam/uptime-kuma:1

check uptime kuma container

docker ps --filter name=uptime-kuma

check logs if not opening

docker logs uptime-kuma

open uptime kuma 

http://43.242.224.163:3001

if port is blocked, allow it

sudo ufw allow 3001/tcp
sudo ufw reload



Configure Email (inside UI)

Go to:

Settings → Notifications → Add → SMTP

Fill:

SMTP Host: smtp.gmail.com
Port: 587
Email + App Password
